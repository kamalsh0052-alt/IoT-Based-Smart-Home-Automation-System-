# 🏠 IoT Smart Home Automation System

A Python-based **IoT Smart Home Automation Dashboard** developed as an ECE mini project.

## 📌 Project Overview

This project demonstrates a smart home automation system using a Python-based graphical dashboard. The dashboard allows users to monitor environmental conditions and control different home appliances.

## ✨ Features

* 💡 Light ON/OFF Control
* 🌀 Fan ON/OFF Control
* ❄️ AC ON/OFF Control
* 🚪 Door Lock/Unlock
* 🤖 Automatic Mode
* 🌡️ Temperature Monitoring
* 💧 Humidity Monitoring
* ⚡ Energy Usage Monitoring
* 🔐 Security & Motion Detection
* 📈 Live Temperature Graph
* 🕒 Real-Time Clock

## 🛠️ Technologies Used

* **Python**
* **Tkinter**
* **Object-Oriented Programming**
* **IoT Concepts**
* **Sensor Data Simulation**

## ▶️ How to Run

### 1. Install Python

Make sure Python is installed on your computer.

### 2. Open the Project Folder

Open PowerShell or Command Prompt inside the project folder.

### 3. Run the Program

```bash
py project.py
```

The Smart Home Automation Dashboard will open.
